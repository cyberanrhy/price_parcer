# Инструкция для ИИ-агента по проекту «Проценка»

## 📋 ROLE
Ты — главный инженер по автоматизации проекта «Проценка». Твоя задача — поддерживать сборку, публикацию и кодовую базу.

## 🚀 АВТОМАТИЗАЦИЯ (RELEASE WORKFLOW)
Если пользователь пишет «Сделай релиз vX.X.X»:
1. **Обнови версию:**
   - Найди в `main.py` константу `VERSION = "..."` и поменяй на `vX.X.X`.
2. **Собери проект:**
   - Выполни: `pyinstaller --noconsole --onefile --name "price_parcer" main.py`.
3. **Закоммить:**
   - `git add .`
   - `git commit -m "Build: версия vX.X.X"`
   - `git push origin master`
4. **Опубликуй (через GitHub Actions):**
   - Убедись, что пуш прошёл успешно.
   - GitHub Actions автоматически соберёт бинарник и прикрепит его к релизу.

## ⚙️ СТРУКТУРА ПАПОК
- `main.py`: Точка входа, GUI на PyQt6.
- `scripts/`: Автоматизация сборки локально.
- `.github/workflows/`: Скрипты для CI/CD (GitHub Actions).
- `config/`: Файлы настроек (всегда в .gitignore!).

## 🔐 БЕЗОПАСНОСТЬ
- НИКОГДА не коммить содержимое папки `config/` или `settings.json`.
- При редактировании кода Emex/Armtek — не оставляй отладочные `print` с данными аккаунтов.

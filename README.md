## 📌 О проекте

**Проценка** — это бесплатная программа с открытым исходным кодом для специалистов по автозапчастям. Она одновременно выполняет поиск по нескольким поставщикам, показывает цены, сроки доставки, кратность (минимальную партию) и позволяет сразу добавлять найденные позиции в корзину поставщика.

Проект создан в первую очередь для пользователей **Skitchen PRO** (система подбора автозапчастей), но может использоваться самостоятельно как универсальный клиент для API поставщиков.

## ✨ Возможности

- **Параллельный поиск** по 7 поставщикам одновременно
- **Сравнение цен** в единой таблице с сортировкой
- **Наценка** — автоматический расчёт продажной цены
- **Корзина поставщика** — добавление найденных позиций напрямую
- **История поиска** с автодополнением
- **Чёрный список брендов** — исключение нежелательных производителей
- **Фильтр поставки Emex** — показывать только позиции с поставкой ≥50%
- **Тайминги запросов** — видно, сколько времени ответил каждый поставщик
- **Проверка IP** — контроль белого IP поставщика

## 🏪 Поддерживаемые поставщики

| Поставщик | Тип API | Поиск | Корзина | Особенности |
|-----------|---------|-------|---------|-------------|
| **Emex** (emex.ru) | SOAP (zeep) | ✓ | ✓ | Фильтр по проценту поставки, кратность |
| **Profit-League** (pr-lg.ru) | REST | ✓ | ✓ | Параллельный поиск по артикулам |
| **Автосоюз** (avtoso-yz.ru) | REST | ✓ | ✓ | Basic Auth, поиск по брендам |
| **Armtek** (armtek.su) | REST | ✓ | ✓ | VKORG + KUNNR_RG параметры |
| **Forum-Auto** (forum-auto.ru) | REST | ✓ | ✓ | Протокол заказа через корзину |
| **Mikado** (mikado.su) | HTTP POST + XML | ✓ | ✓ | Клиентский код + пароль |
| **ABSTD** (abstd.ru) | REST | ✓ | ✓ | md5-авторизация, agreement_id |

## 🚀 Установка

### Из исходного кода

```bash
git clone https://github.com/cyberanrhy/price_parcer.git
cd price_parcer
pip install -r requirements.txt
python main.py
```

### Готовый exe (Windows)

Скачайте последний релиз со страницы [Releases](https://github.com/cyberanrhy/price_parcer/releases) — файл `price_parcer.exe`. Запускайте без установки.

### ⚠️ Примечание для пользователей Windows (SmartScreen)
Так как приложение является бесплатным open-source проектом без платной цифровой подписи, Windows при первом запуске может выдать предупреждение «Windows защитил ваш компьютер».
**Как запустить:**
1. Нажмите «Подробнее» в окне предупреждения.
2. Нажмите появившуюся кнопку «Выполнить в любом случае».
Программа безопасна и не содержит вредоносного кода.

## ⚙️ Настройка

1. При первом запуске откроется страница настроек
2. Заполните учётные данные по каждому поставщику:
   - **Emex**: логин и пароль от личного кабинета ws.emex.ru
   - **Profit-League**: secret key из настроек API pr-lg.ru
   - **Автосоюз**: логин и пароль от avtoso-yz.ru
   - **Armtek**: логин, пароль, VKORG, KUNNR_RG
   - **Forum-Auto**, **Mikado**, **ABSTD**: данные от ЛК каждого поставщика
3. Включите нужных поставщиков чекбоксами
4. Нажмите «Сохранить» для каждого
5. На основной странице введите артикул (и бренд) и нажмите Enter

Данные сохраняются локально:
- В режиме `.py`: `config/settings.json`
- В режиме `.exe`: `%APPDATA%\price_parcer\settings.json`

## 📦 Сборка exe

### Способ 1: Автоматизированный (Рекомендуется)
Если у вас установлен Python, выполните команду в папке проекта:

```bash
pip install pyinstaller
pyinstaller --noconsole --onefile --name "price_parcer" main.py
```
Готовый файл появится в папке `dist/`.

### Способ 2: Через интерфейс (Auto PY to EXE)
Если вы хотите визуально настроить параметры сборки:

```bash
pip install auto-py-to-exe
auto-py-to-exe
```

Настройки в программе: `Onefile`, `Window-based` (скрыть консоль).

## 🔐 Безопасность

- Все учётные данные хранятся **только локально**
- Исходный код **не содержит** тестовых/реальных ключей доступа
- Пароли не передаются третьим лицам
- Программа не требует интернет-подключения к каким-либо серверам, кроме API поставщиков

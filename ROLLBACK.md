# Механизм отката для проекта "Проценка"

## 1. Обзор
Проект реализует механизм отката, позволяющий вернуться к стабильному состоянию в случае ошибок. Механизм включает:
- Создание бэкапов перед изменениями
- Возможность восстановления из бэкапа
- Откат через Git (если изменения отслеживаются)
- Интерактивное предложение отката при ошибках

## 2. Создание бэкапов
Скрипт `scripts/backup.py` автоматически создаёт бэкапы важных файлов перед запуском приложения.

**Важные файлы для бэкапа:**
- `config/settings.json` - настройки приложения
- `main.py` - основной GUI код
- `settings_page.py` - страница настроек
- `theme_manager.py` - если используется (не входит в Git)

Бэкапы хранятся в папке `backups/` внутри директории каждого файла.

## 3. Восстановление из бэкапа
### Автоматическое восстановление
При запуске приложения создаётся бэкап текущих настроек. Если приложение завершается с ошибкой, пользователь может выбрать восстановление.

### Ручное восстановление
Используйте скрипт `scripts/backup.py`:

```bash
# Создание бэкапа
python scripts/backup.py backup main.py

# Восстановление из бэкапа (последний доступный)
python scripts/backup.py restore main.py

# Восстановление из конкретного бэкапа
python scripts/backup.py restore main.py --timestamp 20240101_120000
```

## 4. Откат через Git
Если изменения отслеживаются Git, можно выполнить полный откат:

```bash
git checkout -- .
git clean -f -d
```

**Внимание:** `git clean -f -d` удалит все untracked файлы (включая бэкапы, скриншоты и т.д.)

## 5. Интеграция в приложение
В `main.py` добавлен обработчик ошибок, который при критической ошибке предлагает:
- Вернуться к последнему рабочему состоянию (откат Git)
- Восстановить настройки из бэкапа
- Выйти из приложения

## 6. Ограничения
- Бэкапы хранятся только для файлов, которые были изменены после последнего коммита Git
- Требуется ручное подтверждение при откатах
- Крупные изменения (например, добавление новых провайдеров) лучше делать в отдельной ветке

## 7. Рекомендации
1. Всегда делайте коммиты перед началом работы: `git add . && git commit -m "WIP"`
2. Используйте ветки для новых функций
3. Регулярно создавайте бэкапы важных файлов
4. Проверяйте работоспособность после каждого изменения

## 8. Контакты

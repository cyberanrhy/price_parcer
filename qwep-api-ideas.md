# QWEP API — универсальный посредник для поиска автозапчастей

**Сайт:** https://github.com/qwep-ru/userapi/wiki  

QWEP API — это прокси-сервис, который объединяет множество поставщиков автозапчастей через единый API.  
Позволяет не подключать каждого поставщика отдельно (как мы делаем с Emex и Profit-League), а работать через один шлюз.

## Архитектура
```
Ваше приложение → QWEP API → Сайты поставщиков (Emex, Profit-League и др.)
```

## Авторизация
- Получить Access Token по коду авторизации
- Bearer TOKEN в заголовке `Authorization` всех запросов
- Базовый URL: `https://userapi.qwep.ru`

## Основные методы API

### Поиск товаров
**POST** `/search`

| Параметр | Тип | Описание |
|----------|-----|----------|
| article | text | Артикул для поиска |
| brand | text | Бренд (автораскрытие уточнений) |
| timeout | int | Таймаут в мс (по умолч. 10000) |
| type | 0/1 | 0 — синхронно, 1 — асинхронно |
| accounts | array | ID аккаунтов для поиска (по кому искать) |
| vendors | array | ID поставщиков/филиалов |
| flatView | bool | Все результаты в одном массиве |
| excludePromo | bool | Исключить промо |
| highlightCross | bool | Проверять кроссировку |
| replaceVendorName | bool | Имена аккаунтов вместо поставщиков |

**Ответ (результаты поиска):**
- `searchId` — UUID поиска
- `results[].items[]`:
  - `itemId` — ID результата (для корзины)
  - `article`, `brand`, `title` — артикул, бренд, наименование
  - `price.value` — цена (float)
  - `price.currency` — валюта
  - `quantity.value` — доступное количество
  - `quantity.multiplicity` — кратность товара
  - `delivery` — срок поставки (текст)
  - `deliveryStart`, `deliveryEnd` — даты начала/конца поставки
  - `warehouse` — склад
  - `city` — ID города
  - `originalArticle` — артикул как на сайте поставщика
  - `photo` — URL фото
  - `notes` — доп. информация
  - `info.supplyPercent` — процент поставки (0-100)
  - `info.isMarkdown` — уценка
  - `info.isRefundAvailable` — возможность возврата
  - `info.isUsed` — Б/У товар
  - `info.vendorRating` — рейтинг поставщика (1-5)
  - `info.isDealerWarehouse` — дилерский склад
  - `minQuantity` — мин. количество для заказа
  - `qwepCross` — кросс (1 = кросс запрашиваемого)
  - `status` — статус товара
  - `subway` — метро
- `results[].clarifications[]` — уточнения (бренд, артикул, название, фото)
- `stats.timings.vendor/api` — статистика скорости

### Уточнение бренда перед поиском
Для коротких номеров — получение возможных брендов перед поиском.

### Раскрытие уточнения
Раскрыть `clarificationId` для получения товаров по нему.

### Получение результатов (асинхронно)
`GET /search/results` — все результаты  
`GET /search/updates` — только непросмотренные  
`GET /search/status` — статус поиска

### Корзина
- **Добавление товара** — `POST /cart/add` с itemId
- **Получение корзины** — `GET /cart/list`
- **Очистка корзины** — `POST /cart/clear`
- **Удаление строки** — `POST /cart/remove`
- **Изменение количества** — `POST /cart/update`
- **Типы полей формы корзины** — специфичные поля для каждого поставщика

### Заказы
- **Оформление заказа** — `POST /cart/order`
- **Список заказов** — `GET /orders/list`

### Аккаунты (управление поставщиками)
- Добавление/получение/обновление/удаление аккаунтов
- Установка параметров авторизации для каждого аккаунта

### Справочники
- Поставщики (GET /vendors)
- Города
- Регионы

## Что можно взять для нашей программы "Проценка"

| Идея | Описание | У нас? |
|------|----------|--------|
| **Async search** | Поиск в фоне, результаты по мере готовности | Нет (блокирующий поток) |
| **Multiplicity** | Кратность товара (мин. шаг количества) | Нет |
| **Delivery date range** | Форматированные даты поставки | Нет (только дни) |
| **Vendor rating** | Рейтинг поставщика (1-5) | Нет |
| **Supply percent** | Процент успешных поставок | ✅ уже есть (Emex DDPercent) |
| **Photo URL** | Ссылка на фото товара | Нет (отложено — нет источников) |
| **Clarifications** | Уточнение бренда для коротких номеров | Нет |
| **Cross-check** | Проверка кроссировки | Нет |
| **Flat view** | Все результаты плоским списком | Нет |
| **Supplier accounts** | Возможность добавлять/удалять аккаунты через GUI | Нет |
| **Per-supplier search** | Поиск только по выбранным поставщикам | ✅ (но только 2) |
| **Statistics** | Тайминги выполнения по каждому поставщику | Нет (только общий лог) |

## Вывод
QWEP API предоставляет **значительно более богатую функциональность**, чем наши текущие прямые интеграции.  
Если в будущем захотим расширять программу — можно рассмотреть подключение QWEP как **третьего провайдера** (через его REST API) или даже замену Emex/PL на него.
